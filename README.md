# Web Orbit Tracker (リアルタイム軌跡追跡カメラアプリ)

本アプリは、ブラウザ上で動作する高性能なリアルタイム物体追従・軌跡描画アプリケーションです。
iPadの背面カメラやデスクトップのWebカメラの映像から、画面タッチで指定した任意の対象物をリアルタイムに追尾し、その移動軌跡をCanvas上に美しい発光ネオンラインで描画します。

---

## 🌟 主な特徴

1. **2つの強力な追尾エンジン**
   - **パターン追尾 (Localized Template Matching)**: タップされた対象物のテクスチャ・特徴をパターン画像として保存し、前フレームの周辺領域から高速にマッチング検索を行います。カメラアングルの変更や動きに対して強固です。
   - **カラー追尾 (HSV Color centroid tracking)**: タップされたピクセルのHSV色空間情報をサンプリングし、許容色相範囲内の最大の輪郭を抽出・追尾します。高コントラストなカラーボールや特定の色のマーカーを追従するのに最適です。

2. **超高速・低負荷設計 (60FPSの維持)**
   - iPadやモバイル端末の処理能力を考慮し、カメラ映像の処理用解像度を `640x480` に固定。
   - Template Matchingでは全画面走査を行わず、前フレームの追尾座標を中心とした **「局所探索ウィンドウ」** 内のみを検索することで、WebAssembly処理を数ミリ秒に短縮しています。

3. **洗練されたグラスモルフィズムUI**
   - カメラプレビューをフルスクリーン表示した上に、半透明の美しいガラスエフェクトコントローラーパネルを重ねています。
   - ネオンカラーパレット、軌跡の太さ、軌跡の長さ、色許容範囲などを直感的にスライダー調整可能。

4. **横画面（ランドスケープ）固定＆デバイス回転検知**
   - アプリケーションは横画面使用に最適化されており、デバイスが縦向きの際には自動的にアニメーション付き警告オーバーレイが表示され、デバイスの回転を促します。

## 🚀 ローカルでの動かし方

Webブラウザのセキュリティ制限（Web MediaDevices API）により、**カメラ映像の取得には「HTTPS通信」または「localhostでの通信」が必須**となります。ローカルファイル（`file://index.html`）を直接ダブルクリックして開くとカメラが起動しません。

以下のいずれかの方法で簡易Webサーバーを立ち上げてアクセスしてください。

### 方法1：Pythonを使う（一番簡単）
ターミナルを開き、本フォルダに移動して以下を実行します。
```bash
python3 -m http.server 8000
```
起動後、ブラウザで `http://localhost:8000` にアクセスしてください。

### 方法2：Node.js (npm / npx) を使う
```bash
# http-serverを起動
npx http-server

# または、リアルタイムにコード変更が反映されるbrowser-syncを使用
npx browser-sync start --server --files "css/*.css, js/*.js, *.html"
```

## 🌐 GitHub Pagesへのデプロイ方法 (完全無料)

GitHub Pagesで公開すると、HTTPS環境が自動で提供されるため、iPadやスマートフォンから即座にアクセスしてカメラ機能を使用できます。

1. 新しいGitHubリポジトリを作成します。
2. 本フォルダ内のファイル群をリポジトリにプッシュします。
3. リポジトリの **Settings（設定）** > **Pages** に移動します。
4. **Build and deployment** の「Source」で **Deploy from a branch** を選択し、デプロイするブランチ（例: `main`）とフォルダ（`/ (root)`）を選択して **Save** を押します。
5. 数分後、提供されたHTTPSから始まるURLにiPadのブラウザでアクセスします。

## 💡 トラブルシューティング

- **「Camera access rejected!」と表示される**
  - ブラウザがカメラへのアクセス権限をブロックしています。アドレスバーの鍵アイコンをクリックし、カメラのアクセスを許可してください。
  - HTTPS（暗号化通信）またはlocalhost以外のHTTPサイトからアクセスしていないか確認してください。

- **ロード画面が「WebAssembly moduleをコンパイル中...」のまま進まない**
  - 初回起動時はOpenCV.js (約6.5MB) のダウンロードとWebAssemblyモジュールのコンパイルに数秒〜15秒ほどかかる場合があります。インターネット接続環境をご確認ください。
